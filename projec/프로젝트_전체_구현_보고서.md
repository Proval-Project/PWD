# PWD 프로젝트 전체 구현 보고서

## 1. 프로젝트 개요

### 1.1 프로젝트 목적
PWD(Proval Workflow Dashboard)는 밸브 제조업체의 견적 요청 및 관리 시스템으로, 고객의 견적 요청부터 견적서 작성, 주문 관리, 통계 분석까지 전 과정을 디지털화한 통합 웹 애플리케이션입니다.

### 1.2 기술 스택
- **백엔드**: ASP.NET Core 8.0 (C#)
- **프론트엔드**: React 18 + TypeScript
- **데이터베이스**: MySQL 8.0
- **인증**: JWT (JSON Web Token)
- **차트 라이브러리**: Recharts
- **스타일링**: Tailwind CSS + CSS Modules

### 1.3 시스템 아키텍처
```
┌─────────────────┐
│   Frontend      │  React + TypeScript (포트 3000)
│   (Dashboard)   │
└────────┬────────┘
         │
         ├─────────────────┬──────────────────┐
         │                 │                  │
┌────────▼────────┐ ┌──────▼──────┐ ┌────────▼────────┐
│ EstimateRequest │ │ AuthSystem  │ │ UserManagement  │
│    System       │ │             │ │    System       │
│  (포트 5135)    │ │ (포트 5237) │ │  (포트 5237)    │
└─────────────────┘ └─────────────┘ └─────────────────┘
         │
         │
┌────────▼────────┐
│  ConvalWebApi   │  CONVAL 엔진 연동 (포트 7001)
└────────┬────────┘
         │
┌────────▼────────┐
│     MySQL       │  PWD_Final 데이터베이스
│   Database      │
└─────────────────┘
```

## 2. 데이터베이스 설계

### 2.1 주요 테이블 구조

#### 2.1.1 사용자 관리 테이블
- **User**: 사용자 정보 (UserID, Password, CompanyName, RoleID, IsApproved, IsActive 등)
- **Role**: 역할 정보 (RoleID: 1=Admin, 2=Staff, 3=Customer)

#### 2.1.2 견적 관리 테이블
- **EstimateSheetLv1**: 견적서 헤더 정보
  - TempEstimateNo (PK): 임시 견적번호 (예: TEMP20251128-001)
  - CurEstimateNo: 최종 견적번호
  - Status: 상태 (1=임시저장, 2=견적요청, 3=견적처리중, 4=견적완료, 5=주문)
  - CustomerID, WriterID, ManagerID: 사용자 참조
  - RequestDate, CompleteDate: 날짜 정보

- **EstimateRequest**: 견적 품목 상세 정보
  - TempEstimateNo, SheetID (복합 PK)
  - ValveType: 밸브 타입 코드
  - Tagno: 태그 번호
  - Qty: 수량
  - Medium, Fluid: 유체 정보
  - 액세서리 플래그: IsSolenoid, IsLimSwitch, IsAirSet 등

- **DataSheetLv3**: CONVAL 계산 결과 데이터
  - 계산된 Cv 값, SS100, U1, U2 등
  - 경고 상태 및 타입

- **EstimateAttachment**: 첨부파일 정보
  - CustomerRequest: 고객이 업로드한 파일
  - ResultFiles: 관리자가 업로드한 파일
  - ManagerFileType: 파일 타입 구분

#### 2.1.3 마스터 데이터 테이블
- **BodyValveList**: 밸브 시리즈 목록
- **BodySizeList**: 밸브 사이즈 목록
- **TrimTypeList**: 트림 타입 목록
- **ActTypeList**: 액추에이터 타입 목록
- **PositionerMakerList, SolenoidMakerList 등**: 액세서리 제조사 및 모델 목록

### 2.2 데이터베이스 관계
- User ↔ EstimateSheetLv1: 1:N (CustomerID, WriterID, ManagerID)
- EstimateSheetLv1 ↔ EstimateRequest: 1:N (TempEstimateNo)
- EstimateSheetLv1 ↔ DataSheetLv3: 1:N (TempEstimateNo)
- EstimateSheetLv1 ↔ EstimateAttachment: 1:N (TempEstimateNo)

## 3. 백엔드 시스템 구현

### 3.1 인증 시스템 (AuthSystem)

#### 3.1.1 주요 기능
- **회원가입**: 사용자 등록 및 관리자 승인 대기
- **로그인**: JWT 토큰 기반 인증
- **비밀번호 재설정**: 이메일 인증 코드 기반
- **아이디 찾기**: 이메일로 아이디 안내
- **사용자 승인**: 관리자가 회원가입 요청 승인/거부

#### 3.1.2 보안 기능
- SHA256 기반 비밀번호 해싱
- JWT 토큰 발급 및 검증
- 역할 기반 접근 제어 (RBAC)
- 이메일 인증 코드 시스템

#### 3.1.3 주요 API 엔드포인트
```
POST /api/auth/register          - 회원가입
POST /api/auth/login             - 로그인
POST /api/auth/forgot-password   - 비밀번호 재설정 요청
POST /api/auth/reset-password    - 비밀번호 재설정
POST /api/auth/find-id           - 아이디 찾기
POST /api/auth/approve-user/{id} - 사용자 승인
GET  /api/auth/pending-users     - 승인 대기 사용자 목록
```

### 3.2 견적 요청 시스템 (EstimateRequestSystem)

#### 3.2.1 주요 기능

**1. 견적서 관리**
- 견적서 생성 (임시저장/견적요청)
- 기존 견적서 복사 (재문의)
- 견적서 조회 (상태별, 사용자별)
- 견적서 수정 및 삭제

**2. 견적 품목 관리**
- 품목 추가/수정/삭제
- 품목 순서 변경
- 밸브 사양 입력 (Body, Trim, Actuator)
- 액세서리 선택 (Positioner, Solenoid, Limit Switch 등)

**3. 파일 관리**
- 고객 첨부파일 업로드 (CustomerRequest)
- 관리자 결과 파일 업로드 (ResultFiles)
- 파일 다운로드 및 삭제

**4. CONVAL 엔진 연동**
- XML 데이터 생성 및 전송
- 계산 결과 수신 및 저장
- Excel 견적서 생성 (CV, DS, VL, MultiQuote, SingleQuote)

**5. 통계 분석**
- 워크플로우 통계: 상태별 건수, 상태 분포, 전환율
- 제품 통계: 밸브 사양 비율, 월별 수주 현황

- Status 3 (견적처리중): 관리자가 견적서 처리 중

- EstimateRequest 테이블의 IsSolenoid, IsLimSwitch 등 플래그에 따라

## 5. 통계 시스템 상세 구현

### 5.1 데이터 집계 로직

#### 5.1.1 워크플로우 통계
- **필터 조건**: `Status >= 2` (임시저장 제외)
- **집계 방식**: COUNT(DISTINCT TempEstimateNo)
- **상태 매핑**:
  - Status 2 → 견적요청
  - Status 3 → 견적처리중
  - Status 4 → 견적완료
  - Status 5 → 주문

#### 5.1.2 제품 통계
- **필터 조건**: `Status >= 2` (임시저장 제외)
- **집계 방식**: SUM(Qty) - 수량 합계
- **그룹핑**:
  - 밸브 사양 비율: ValveType별
  - 월별 수주 현황: DATE_FORMAT(RequestDate, '%Y-%m')별

#### 5.1.3 전환율 계산
- **분자**: ActualOrders (Status = 5)
- **분모**: CompletedQuotes (Status >= 4)
- **공식**: (ActualOrders / CompletedQuotes) × 100
- **예외 처리**: NULLIF로 0으로 나누기 방지

### 5.2 프론트엔드 차트 구현

#### 5.2.1 사용 라이브러리
- **Recharts**: React 차트 라이브러리
  - BarChart: 막대 그래프
  - PieChart: 파이/도넛 차트
  - ComposedChart: 복합 차트

#### 5.2.2 차트 컴포넌트
- **StatusCardList**: 상태별 건수 카드
- **StatusDistributionChart**: 상태 분포 막대 그래프
- **ConversionRateComposedChart**: 전환율 복합 차트
- **ValveRatioDonutChart**: 밸브 사양 비율 도넛 차트
- **MonthlyOrderChart**: 월별 수주 현황 막대 그래프

## 6. 파일 관리 시스템

### 6.1 파일 저장 구조
```
files/
└── TEMP{YYYYMMDD}-{순번}/
    ├── CustomerRequest/    # 고객이 업로드한 파일
    └── ResultFiles/        # 관리자가 업로드한 파일
```

### 6.2 파일 타입 구분
- **CustomerRequest**: 고객이 견적 요청 시 업로드
- **ResultFiles**: 관리자가 견적 처리 후 업로드
  - ManagerFileType: "customer" (고객 제출 문서)
  - ManagerFileType: 기타 (관리자 생성 문서)

### 6.3 파일 필터링 로직
- "관리 첨부파일" 섹션: ResultFiles 폴더 내 ManagerFileType="customer"만 표시
- CustomerRequest 폴더 파일은 별도 섹션에 표시

## 11. 기술적 특징

### 11.1 백엔드
- **아키텍처**: RESTful API, 3-Tier Architecture (Controller-Service-Repository)
- **ORM**: Entity Framework Core
- **데이터베이스**: MySQL 8.0
- **인증**: JWT Bearer Token
- **CORS**: Cross-Origin Resource Sharing 지원

### 11.2 프론트엔드
- **프레임워크**: React 18 with TypeScript
- **상태 관리**: React Hooks (useState, useEffect, useCallback)
- **라우팅**: React Router DOM
- **HTTP 클라이언트**: Axios
- **차트**: Recharts
- **스타일링**: Tailwind CSS + CSS Modules

### 11.3 데이터베이스
- **정규화**: 3NF 이상
- **인덱스**: Primary Key, Foreign Key, UNIQUE 제약조건
- **트랜잭션**: Entity Framework Core SaveChangesAsync
- **데이터 무결성**: Foreign Key 제약조건, CASCADE/RESTRICT 정책
